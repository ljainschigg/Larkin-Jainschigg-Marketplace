# example-skill

A placeholder skill used to validate the Claude Plugins Marketplace pipeline.

---

## Install

If you haven't added the marketplace yet:

```
/plugin marketplace add ljainschigg/Larkin-Jainschigg-Marketplace
```

Then install the plugin:

```
/plugin install example-skill@claude-plugins
```

## Use

```
/example-skill
```

Claude will confirm that the marketplace pipeline is working correctly.
