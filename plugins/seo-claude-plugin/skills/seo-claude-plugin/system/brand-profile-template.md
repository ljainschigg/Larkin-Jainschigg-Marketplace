# Brand profile (instance configuration)

your organization and reuse it across articles. Keep it wherever you keep your
reference material (a project folder, a private repo) and point the workflow at
it when asked. Nothing here ships with the plugin.

The workflow uses this to:
- seed the brand perspective for each article (step 03),
- decide which sources to exclude or prefer during research (step 04),
- optionally locate product documentation to draw on while writing.
